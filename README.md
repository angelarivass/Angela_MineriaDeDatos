# Data Mining

Coursework, assignments, and exercises developed for the Data Mining course, part of the Software Engineering program at CETYS Universidad.

## Contents

This repository includes Jupyter notebooks covering hands-on exercises and analysis across several course topics:

- **Data Geometry** (`05-DataGeometry`, `06-DataGeometry`): exercises on data representation and geometric interpretation of datasets.
- **Titanic Dataset** (`titanic-1`, `titanic-2`, `titanic-3`): exploratory data analysis and data cleaning on the classic Titanic dataset, including handling missing values and preparing data for modeling.
- **Google Play Store** (`google_play.ipynb`): exploratory data analysis on the Google Play Store dataset (`googleplaystore.csv`), including data cleaning, transformation, and visualization.
- **Parsers** (`parser.ipynb`, `parser-advanced.ipynb`): exercises on data extraction and processing.
- **Unit 3**: activities corresponding to the third unit of the course.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib / Seaborn (data visualization)

## Purpose

This repository documents hands-on practice with core data mining concepts, including data cleaning, exploratory data analysis (EDA), working with real-world datasets, and preparing data for machine learning tasks.
